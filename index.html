📖 使い方

基本操作

  • PDFを開く: ヘッダー「開く」または D&D
  • ページ並び替え: サムネをドラッグ
  • 複数選択: Ctrl/⌘+クリック または Shift+クリック（範囲）
  • 全選択: Ctrl+A（サムネにフォーカス時）
  • 一括削除: 複数選択 → Delete または「🗑️ 削除」
  • 一括回転: 複数選択 → ↺ / ↻
  • 選択ページ抽出: 選択ページのみで新PDF生成

注釈ツール

  • T テキスト、🖍️ ハイライト、▭ ◯ ➤ 図形、✏️ フリーハンド、📌 付箋
  • 注釈の一括選択: ツールバー「全選択」
  • Delete: 選択中の注釈を削除

高度な機能

  • ↶ ↷ アンドゥ/リドゥ (Ctrl+Z / Ctrl+Y)
  • 📋 フォーム 既存PDFフォームを検出して入力
  • 🔍 OCR 画像PDFからテキスト抽出 (日英中韓対応)
  • ✍️ 署名 手書き署名または画像で署名スタンプ
  • ⇆ 比較 別PDFを並べて表示
  • 💾 自動保存 編集状態を localStorage に保存（同じPDFを開くと復元）

キーボードショートカット

  • ←/→ 前後ページ / Ctrl+Z Undo / Ctrl+Y Redo
  • Ctrl+A 全選択 / Ctrl+S 保存 / Delete 削除
  • +/- ズーム / Esc モーダル閉じる
